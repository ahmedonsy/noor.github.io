# موقع جنة الرحمن (مستقل بالكامل)

## التشغيل
افتح `index.html` بالضغط المزدوج. لا يحتاج Node.js ولا سيرفر ولا إنترنت.
لوحة التحكم: `admin.html` (أو رابط "لوحة الإدارة" أسفل الموقع). أول مرة تُنشئ كلمة مرور.

## الهيكل
- `index.html` الموقع، `admin.html` لوحة التحكم
- `css/` التصميم، `js/store.js` الموقع، `js/admin.js` اللوحة، `js/storage.js` طبقة البيانات
- `js/data.js` البيانات الأصلية (المنتجات والإعدادات) — منفصلة عن الكود
- `assets/images/products/` صور المنتجات، `backup/sample-backup.json` نسخة احتياطية تجريبية

## إضافة وتعديل المنتجات
من اللوحة: تبويب المنتجات ← منتج جديد / تعديل / حذف. الصور: ارفعها من الجهاز، أو ضع الملف في `assets/images/products/` وأدخل مساره.

## حفظ البيانات (مهم)
تعديلاتك تُحفظ في LocalStorage داخل **متصفحك فقط**. زوار الموقع لا يرونها تلقائيًا.
للنشر: لوحة التحكم ← النسخ الاحتياطي والنشر ← "تنزيل data.js" ← استبدل به `js/data.js` ← ارفع المجلد.
حد التخزين المحلي حوالي 5MB، لذلك فضّل وضع الصور في المجلد بدل رفعها داخل اللوحة.
النسخ الاحتياطي: تصدير/استيراد JSON من نفس التبويب.

## نقل الموقع
انسخ المجلد كاملًا إلى أي جهاز. (البيانات المحلية تبقى في المتصفح القديم: صدّرها هناك ثم استوردها هنا.)

## الأمان
كلمة مرور اللوحة تُخزَّن مُشفّرة (SHA-256) في متصفحك، وهي حماية بسيطة لأن الموقع بلا سيرفر. من يملك الملفات يستطيع تجاوزها. لإدارة حقيقية متعددة المستخدمين يلزم سيرفر وقاعدة بيانات.
نسيت كلمة المرور؟ امسح بيانات الموقع من المتصفح.

## التطوير مستقبلًا
السلة والطلبات والدفع والحسابات تحتاج سيرفر وقاعدة بيانات؛ طبقة `storage.js` معزولة لتسهيل استبدالها بقاعدة مركزية.
الطلب الحالي عبر رابط واتساب (يفتح موقع wa.me، ويحتاج إنترنت عند الضغط فقط).
